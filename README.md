# TradeMind-MLOps

## Zusammenfassung
TradeMind-MLOps ist ein konzeptionelles Assistenzsystem, das mithilfe von Machine-Learning-Algorithmen historische Marktdaten analysiert. Das System dient Privattratern als digitaler Filter, um emotionales Rauschen und Panikreaktionen an volatilen Märkten zu minimieren.

## Hintergrund
Ich bin vor einiger Zeit selbst aktiv in das Trading eingestiegen. Das System soll Privattradern helfen, emotionale Fehlentscheidungen zu vermeiden.

## Daten und KI-Techniken
Das Projekt nutzt historische Kursdaten und wendet die Naive-Bayes-Klassifikation sowie die Nächste-Nachbarn-Klassifikation an.

## Wie wird es eingesetzt?
Das System läuft als Cloud-Infrastruktur im Hintergrund und dient dem Trader als digitaler Co-Pilot bei Entscheidungen.

## Herausforderungen
Das System kann unvorhersehbare Markt-Events (Black Swan) nicht vorhersagen und ersetzt kein eigenes Risikomanagement.

## Wie geht es weiter?
Ausbau der automatisierten Daten-Pipeline in der Cloud (MLOps) und Integration von Reinforcement Learning.

## Danksagung
Inspiration durch den Kurs Elements of AI. Daten über Open-Source-Finanz-APIs.
